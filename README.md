# Thrift Spotter data

`hitlist.json` is the brand hit list the Thrift Spotter app downloads:

https://raw.githubusercontent.com/delanean1/ThriftSpotter-data/main/hitlist.json

Generated from the Thrift Hit List spreadsheet with `tools/export_hitlist.py` in the
private ThriftSpotter repo. Contains brand names, label text, and eBay/Poshmark price
numbers only.
